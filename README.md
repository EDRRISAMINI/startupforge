# Zehn Barter

Zehn Barter is a free AI startup studio for turning ideas into product strategy, startup plans, market analysis, MVP plans, and technical roadmaps.

## Features

- Idea-to-startup workflow
- Multi-agent product and market analysis
- Technical blueprint and MVP roadmap
- Dashboard for startup generation
- Completely free to use

## Getting started

```bash
npm install
npm run dev
```

## Notes

This project is designed as a free, open-access founder tool. There are no paid plans or premium gates.
